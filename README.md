INTRODUCTION TO GIT & GITHUB

GIT :
git is a distributed version control system created to track and manage code efficiently..
it is used for :
change tracking 
commit history storing
code rollback

github:
the github is cloud based platform that is hold repositories online..
it is used for:
storing code
repo sharing 
team collabortion
CI/CD integration

why developer use git..?
Git is used by developers to:

* Save code history
* Track changes
* Work with team members
* Create separate branches for new features
* Recover old code if something breaks
* Upload projects to [GitHub](https://github.com?utm_source=chatgpt.com)

Simple meaning:
 Git helps developers manage and protect their code easily.
